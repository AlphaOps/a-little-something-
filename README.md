# A Little Something 💌

A beautifully animated, interactive scrapbook and digital letter experience built for a special someone. 

## Features

- **Interactive Scrapbook Pages**: Smooth scrolling transitions between custom-designed pages.
- **Handwritten Letter Animation**: Dynamic typewriter and handwriting effects simulating a real letter being written in real-time.
- **Embedded Music Player**: A floating, cross-page music player that persists across interactions.
- **Fully Responsive**: Optimized seamlessly across iOS (iPhone 15, Pro, Pro Max), Android, and Desktop devices.
- **Optimized Assets**: Fallbacks for all visual elements ensure the experience remains clean even if an asset fails to load.

## Tech Stack

- **HTML5** & **CSS3**: No heavy frameworks. Pure, performant layout using Flexbox, CSS Grid, and custom animations.
- **Vanilla JavaScript**: Lightweight interactions, IntersectionObservers for scroll tracking, and custom typewriter logic.

## Deployment Instructions (Vercel)

This project is entirely static and requires no build step! It can be deployed to Vercel in seconds.

1. Create a free account at [Vercel](https://vercel.com).
2. Click **Add New Project**.
3. Import this GitHub repository (`a-little-something`).
4. Skip the build commands (leave Framework Preset as `Other` and Build Command empty).
5. Click **Deploy**.

Within seconds, your interactive scrapbook will be live on a fast, global CDN!
